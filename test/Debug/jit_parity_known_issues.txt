# Known -dap/JIT parity issues — baseline for `jit_parity_sweep.py --gate`.

# Each line is a path relative to examples/ that the -dap JIT lane does not
# yet run clean. A failure listed here is tolerated by the gate; a failure
# NOT listed is a regression and fails CI. An entry that now passes is
# reported as STALE (prune it) but does not fail the gate.
#
# (The gate retries a CRASH/HANG once before counting it, so a one-off flake
#  on an otherwise-clean example won't turn CI red.)

# `-dap` JIT lane. Add an entry only for a genuine, reproduced residual.

# Pruned 2026-06-01 (#77):
#   - quadrotor/quadrotor_derive_eom.m — was a SymPP-backed `syms` example
#     wrongly in scope (the sym-skip heuristic only scanned the first 20
#     lines; its `syms` declaration is ~line 28). Now correctly SKIPped.
#   - pde/antenna_glb_fem.m, pde/antenna_wind_stress.m — load an external
#     GLB model from /tmp that doesn't ship with the repo. The "intermittent

#     REPL/JIT workspace round-trip resurrected it as a garbage struct. The
#     NULL round-trip is now hardened (matlab_ws_set_struct kind=12 +
#     matlab_struct_get_mat null pass-through), and the sweep now SKIPs
#     examples whose referenced model file is absent (environment-dependent,
#     like the sym examples needing SymPP).

# Pruned 2026-06-01 (#105):
#   - dlnet/dl_classdef_array_literal.m — NOT an object-lifetime UAF as first
#     hypothesised. Root cause was a lowering divergence: an `[A; B; C]`
#     object-array literal over classdef-instance *vars* fell through to
#     matlab_vertcat in ReplMode (the LowerTensorOps OA-literal detector keys
#     off the operand's defining op — a classdef-method call or class_id alloc
#     load — which only matches the AOT lane; in ReplMode the vars read via
#     matlab_ws_get_mat, so it missed them). The garbage "matrix" was then
#     deref'd as an obj by objArrayGet/extractdata → intermittent SIGSEGV.
#     Fixed by an AST-level detector in Lowering (keys off Ref->PinnedClass,
#     fires on both lanes). Now runs clean + correct (PASS) on AOT/-repl/-dap.
